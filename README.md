## 3. How SMS-Activate Review Works

The basic SMSPool workflow is simple:

1. Select the service that will send the OTP.
2. Choose the required country.
3. Order a number.
4. Enter the number on the target service.
5. Wait for the verification SMS.
6. Read the OTP in the SMSPool interface or through the API.
7. Complete the verification process.

The selected country determines the country associated with the provided number.

For developers, the REST API provides programmatic access to number ordering and incoming OTP messages. This can be useful when SMS verification is part of an automated test suite.
